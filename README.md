# Hermess-One: Система анализа инженерной документации

Система для проверки рабочей документации по инженерным сетям на соответствие НТД РФ.

## Установка на Proxmox (Ubuntu 22.04)
1. `git clone https://github.com/gubarandrej-bit/hermess-one.git`
2. `cd hermess-one`
3. `docker-compose up -d --build`
